# Randičko web

Jednoduchý mobilní web připravený pro GitHub Pages.

## Soubory

- `index.html` – úvodní otázka
- `ano.html` – stránka po kliknutí na Ano
- `styles.css` – vzhled
- `script.js` – error hláška po kliknutí na Ne
- `confetti.js` – konfety
- `randicko-4-10.ics` – událost pro Apple Kalendář

## GitHub Pages

1. Na GitHubu vytvoř nový repository, například `randicko`.
2. Nahraj všechny soubory z této složky.
3. Otevři `Settings`.
4. Vlevo klikni na `Pages`.
5. U `Build and deployment` vyber:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Klikni na `Save`.

Adresa potom bude přibližně:

`https://TVE-JMENO.github.io/randicko/`

## Visual Studio Code

1. Rozbal ZIP.
2. Ve VS Code zvol `File > Open Folder`.
3. Vyber složku projektu.
4. Pro náhled můžeš nainstalovat rozšíření `Live Server`.
5. Klikni pravým na `index.html` a vyber `Open with Live Server`.
